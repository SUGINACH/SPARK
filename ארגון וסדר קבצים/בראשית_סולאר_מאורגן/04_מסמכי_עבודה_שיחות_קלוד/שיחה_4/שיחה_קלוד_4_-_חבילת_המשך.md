# חבילת המשך (Continuation Bundle) — מחשבון תעו"ז ואגירה סולארית

> נכתב לצורך העברת קונטקסט מלא לשיחת Claude חדשה (חשבון אחר). קרא/י את המסמך הזה **במלואו** לפני שמתחילים לפעול — הוא מכיל את כל ההיסטוריה, ההחלטות, הבאגים שתוקנו, וממצאי ביקורת שטרם יושמו.

---

## 1. מטרת העל של הפרויקט

בניית **מחשבון סולארי-אגירה בעברית (RTL)**, בצורת אפליקציית דף-יחיד (SPA) הרצה כולה בדפדפן (ללא שרת/backend), שמבצעת שלושה שלבים רצופים:

1. **ניתוח צריכה** — המשתמש מעלה קובץ CSV גולמי מהאזור האישי בחברת החשמל (חח"י), והמערכת מנתחת אותו לפי כללי תעו"ז המלאים (חורף/קיץ/מעבר, שבתות, חגים 2020-2030) ומפיקה סטטיסטיקות צריכת-פסגה (חציון, ממוצע מנוכה 15%, קיצוניים).
2. **חישוב הנדסי-פיננסי** — לפי שטח גג, כיוון, הצללה, ודרישות הלכתיות (גיבוי שבת/חג) — מחשב גודל מערכת (Pdc/Pac), גודל סוללה, ותחזית פיננסית ל-25 שנה (CAPEX, מימון, IRR, NPV) כ"תצוגה מקדימה" (מניחה ברירת מחדל של אפשרות הזרמה, ללא פרמיה אורבנית).
3. **חישוב סופי** — מוסיף את שני הפרמטרים הרגולטוריים שנקבעים רק בעת אישור חיבור בפועל (מגבלת Zero Export, זכאות לפרמיה אורבנית), ומריץ את החישוב הפיננסי **הסופי והמחייב**, עם ייצוא Excel מלא.

**נקודת מוצא:** המשתמש סיפק קובץ HTML קיים אחד (`ai_studio_code__2_.html`, בקובץ מקורי שהועלה) שהכיל את כל שלוש היכולות מבולגנות בדף אחד ללא הפרדה בין שלבים, וללא שמירת מצב. הפרויקט כולו הוא **סבב שיפורים איטרטיבי** על הקובץ הזה.

**חשוב:** זהו כלי ייעוץ/תכנון להערכה בלבד — לא תחליף לייעוץ הנדסי-חשמלי, מיסויי, או משפטי מוסמך. התעריפים והחוקים המשולבים בו דורשים אימות תקופתי (ראו סעיף "ממצאי ביקורת" למטה).

## 3. סטטוס נוכחי של הקוד

### ✅ מה שעובד ומתפקד (נבדק ואומת):
- **שלושת השלבים** רצים בתוך דף אחד (`solar-calculator-spa.html`), עם ניווט פנימי (`showSection(n)`) שמחליף `<div class="spa-section">` גלוי/מוסתר — **אין ניווט אמיתי בין דפים**, אין hard reload.
- **6 באגים הנדסיים/פיננסיים תוקנו ואומתו** (ראו טבלה בסעיף 3.1 למטה) ביחס לקובץ ה-HTML המקורי שהמשתמש סיפק.
- **בדיקות אוטומטיות עברו במלואן**: יחידה (Node `--check` על ה-JS המחולץ), אינטגרציה מלאה (jsdom מדמה זרימת משתמש מקצה לקצה על שלושת השלבים באותה טעינת דף, כולל שחזור localStorage בין מעברי סקשן).
- **ייצוא Excel** עובד בכל שלושת השלבים (`exportToExcel1/2/3`), עם גיליונות נפרדים לכל דוח.
- **מודל הגדרות תעריפים** (`⚙️ הגדרות תעריפי תעו"ז`, מודל popup) משותף לכל 3 השלבים ומסתנכרן דרך `localStorage.solarCalc_constants`.

### ⚠️ מה שעדיין לא בוצע (זוהה אך לא תוקן בקוד עדיין):
- **דו"ח ביקורת מלא** (`דוח_ביקורת.md`) זיהה **12 ממצאים נוספים** — **אף אחד מהם עדיין לא יושם בקוד**. זו בדיוק "המשימה הבאה בתור" (סעיף 6 למטה).
- 3 מהממצאים דורגו 🔴 **קריטי**: (א) מבנה מס פרטי לא תואם את המנגנון האמיתי בחוק, (ב) פרמיה אורבנית לא מיושמת על צריכה עצמית ב-Zero Export, (ג) שיעור צריכה עצמית (40%) קבוע ולא גדל עם גודל הסוללה.

### 🗂️ קבצים שכבר הורדו/נבדקו על ידי המשתמש:
לפי דברי המשתמש בתחילת השיחה הזו: "אני כבר יוריד לבד את הקבצים שיצרת" — כל הקבצים המפורטים בסעיף 4 כבר קיימים אצל המשתמש/יורדו על ידו מהשיחה המקורית. **אין צורך להציג present_files מחדש** אלא אם מבקשים זאת מפורשות.

function pmt(rate, nper, pv) { return rate === 0 ? -(pv / nper) : -(rate * pv) / (1 - Math.pow(1 + rate, -nper)); }
function npv(rate, cf) { return cf.reduce((s, v, i) => s + v / Math.pow(1 + rate, i), 0); }
function irr(cf, g = 0.1) {
    let x = g;
    for (let i = 0; i < 100; i++) {
        const n = npv(x, cf), d = cf.reduce((s, v, j) => s - j * v / Math.pow(1 + x, j + 1), 0);
        if (!d) return NaN;
        const x1 = x - n / d;
        if (Math.abs(x1 - x) < 1e-7) return x1;
        x = x1;
    }
    return NaN;
}
function calculateBlendedFitTariff(p0, pAc, zeroExport, isUrban) {
    if (zeroExport || pAc <= 0) return 0;
    const total = p0 + pAc, t1 = 15, t2 = 100;
    const in1 = Math.max(0, Math.min(total, t1) - p0);
    const in2 = Math.max(0, Math.min(total, t2) - Math.max(p0, t1));
    const in3 = Math.max(0, total - Math.max(p0, t2));
    let tariff = (in1 * CALC_CONSTANTS.tariffs.fit_0_15 + in2 * CALC_CONSTANTS.tariffs.fit_15_100 + in3 * CALC_CONSTANTS.tariffs.fit_100_300) / pAc;
    if (isUrban) tariff += CALC_CONSTANTS.urban_premium;
    return tariff;
}
function runEngineeringCalc(inputs) {

    if (inputs.useStorageHoliday)  batteryKwh = Math.max(batteryKwh, (inputs.estShabbatLoad * 2) / uf);
    else if (inputs.useStorageShabbat) batteryKwh = Math.max(batteryKwh, inputs.estShabbatLoad / uf);
    return { pDc, pAc, annualYield, batteryKwh };
}
function runFinancialModel(pAc, pDc, batKwh, annualYield, tariff, inputs, peakStats) {
    const pvCost = pAc * inputs.capexPV, batCost = batKwh * inputs.capexBattery;
    let capex = pvCost + batCost;
    if (inputs.taxStatus === 'business') capex /= 1.17;
    const loan = capex * inputs.loanPct, equity = capex - loan;
    const pmtY = Math.abs(pmt(inputs.loanInt, inputs.loanYrs, loan));
    const avgT = (CALC_CONSTANTS.tou.summer_peak + CALC_CONSTANTS.tou.summer_low +
                  CALC_CONSTANTS.tou.winter_peak + CALC_CONSTANTS.tou.winter_low +
                  CALC_CONSTANTS.tou.transition_peak + CALC_CONSTANTS.tou.transition_low) / 6;
    let cf = [-equity], profit = 0, bal = loan;
    for (let y = 1; y <= 25; y++) {
        const ep = annualYield * Math.pow(1 - CALC_CONSTANTS.degradation, y - 1);
        let revSolar = inputs.zeroExport ? ep * SELF_CONSUMPTION_RATE * avgT : ep * tariff;
        let revArb = 0, revGen = 0;
        if (batKwh > 0) {
            const ub = batKwh * CALC_CONSTANTS.battery.dod * CALC_CONSTANTS.battery.eff_discharge;
            const ss = (peakStats && peakStats.summer && peakStats.summer.trimmedKwh) ? Math.min(ub, peakStats.summer.trimmedKwh) : ub;
            const sw = (peakStats && peakStats.winter && peakStats.winter.trimmedKwh) ? Math.min(ub, peakStats.winter.trimmedKwh) : ub;
            revArb = ARBITRAGE_DAYS.summer * ss * (CALC_CONSTANTS.tou.summer_peak - CALC_CONSTANTS.tou.summer_low)
                   + ARBITRAGE_DAYS.winter * sw * (CALC_CONSTANTS.tou.winter_peak - CALC_CONSTANTS.tou.winter_low);
            if (inputs.ignoreMissingShabbat && (inputs.useStorageShabbat || inputs.useStorageHoliday))
                revGen = 50 * inputs.estShabbatLoad * inputs.genCost;
        }
        const rev = revSolar + revArb + revGen;
        const opex = pAc * CALC_CONSTANTS.opex.pv + batKwh * CALC_CONSTANTS.opex.battery;
        const fin = y <= inputs.loanYrs ? pmtY : 0;
        let intY = 0;
        if (y <= inputs.loanYrs && loan > 0) { intY = bal * inputs.loanInt; bal -= pmtY - intY; }
        let repl = 0;
        if (y === CALC_CONSTANTS.replacements.inverter_year) repl += pvCost * CALC_CONSTANTS.replacements.inverter_cost_pct;
        if (batKwh > 0 && y === CALC_CONSTANTS.replacements.battery_year) repl += batCost * CALC_CONSTANTS.replacements.battery_cost_pct;
        let tax = 0;
        if (inputs.taxStatus === 'private') { if (rev - opex > 25000) tax = (rev - opex - 25000) * 0.10; }
        else { const dep = y <= 4 ? capex * 0.25 : 0; const ti = rev - opex - dep - intY; if (ti > 0) tax = ti * 0.23; }
        const net = rev - opex - repl - tax - fin;
        cf.push(net); profit += net;
    }
    const irrV = irr(cf);
    return { capex, equity, capacity: pAc, batKwh, totalProfit: profit, irr: isFinite(irrV) ? (irrV * 100).toFixed(2) : 'N/A', npv: npv(0.05, cf).toFixed(0) };
}

function calcMedian(a) { if (!a.length) return 0; const s = [...a].sort((x,y)=>x-y), m = Math.floor(s.length/2); return s.length%2 ? s[m] : (s[m-1]+s[m])/2; }
function calcTrimmedMean(a, p=0.15) { if (!a.length) return 0; const s=[...a].sort((x,y)=>x-y), c=Math.round(s.length*p); let t=s.slice(c,s.length-c); if (!t.length) t=s; return t.reduce((x,y)=>x+y,0)/t.length; }
function calcTopPct(a, p=0.15) { if (!a.length) return 0; const s=[...a].sort((x,y)=>y-x), c=Math.max(1,Math.round(s.length*p)); return s.slice(0,c).reduce((x,y)=>x+y,0)/c; }
function calcBotPct(a, p=0.15) { if (!a.length) return 0; const s=[...a].sort((x,y)=>x-y), c=Math.max(1,Math.round(s.length*p)); return s.slice(0,c).reduce((x,y)=>x+y,0)/c; }
function getStats(kwhArr, costArr) {
    return { medianKwh: calcMedian(kwhArr), medianCost: calcMedian(costArr), trimmedKwh: calcTrimmedMean(kwhArr), trimmedCost: calcTrimmedMean(costArr), top15Kwh: calcTopPct(kwhArr), bottom15Kwh: calcBotPct(kwhArr) };
}

function renderReports(hourly, daily, tou) {
    document.getElementById('reportsContainer').style.display = 'flex';
    document.getElementById('exportExcelBtn_1').style.display = 'flex';
    document.getElementById('analyticsRowsContainer').style.display = 'flex';

    let hrHtml = '';
    for (const [t, d] of Object.entries(hourly)) hrHtml += `<tr><td>${t}</td><td class="day-cell">${d.day}</td><td>${d.kwh.toFixed(2)}</td></tr>`;
    document.querySelector('#hourlyTable tbody').innerHTML = hrHtml;

    let mergedHtml = '', peakHtml = '';
    const pkC = [], pkCost = [], pkW = [], pkWCost = [], pkS = [], pkSCost = [];

    for (const date in daily) {
        const day = daily[date].day, total = daily[date].kwh, offP = tou[date].offPeak, peak = tou[date].peak;
        mergedHtml += `<tr><td>${date}</td><td class="day-cell">${day}</td><td><strong>${total.toFixed(2)}</strong></td><td class="offpeak-cell">${offP.toFixed(2)}</td><td class="${peak>0?'peak-cell':''}">${peak>0?peak.toFixed(2):'-'}</td></tr>`;
        if (peak > 0) {
            const mo = parseInt(date.split('/')[1], 10);
            let t2 = CALC_CONSTANTS.tou.transition_peak, season = 'trans';
            if ([12,1,2].includes(mo)) { t2 = CALC_CONSTANTS.tou.winter_peak; season = 'winter'; }
            else if (mo >= 6 && mo <= 9) { t2 = CALC_CONSTANTS.tou.summer_peak; season = 'summer'; }
            const cost = peak * t2;
            pkC.push(peak); pkCost.push(cost);
            if (season === 'winter') { pkW.push(peak); pkWCost.push(cost); }
            else if (season === 'summer') { pkS.push(peak); pkSCost.push(cost); }
            peakHtml += `<tr><td>${date}</td><td class="day-cell">${day}</td><td class="peak-cell">${peak.toFixed(2)}</td><td>₪${cost.toFixed(2)}</td></tr>`;
        }
    }
    document.querySelector('#dailyMergedTable tbody').innerHTML = mergedHtml;
    document.querySelector('#peakOnlyTable tbody').innerHTML = peakHtml;

    const sC = getStats(pkC, pkCost), sW = getStats(pkW, pkWCost), sS = getStats(pkS, pkSCost);
    globalCalculatedStats = { combined: sC, winter: sW, summer: sS };
    populateDOM('c', sC); populateDOM('w', sW); populateDOM('s', sS);
}

## 6. המשימה הבאה בתור

**המשימה המדויקת שהייתה אמורה להתבצע לפני קיצור השיחה:** יישום התיקונים שזוהו ב-`דוח_ביקורת.md` **בתוך `solar-calculator-spa.html`** (ולא רק תיעוד שלהם — עד כה בוצע **רק אבחון**, אין עדיין שינוי קוד בעקבות דוח הביקורת). לא נתבקשתי עדיין באיזה סדר/היקף לתקן — זו ההחלטה שממתינה למשתמש/לשיחה הבאה.

**סדר עדיפויות מוצע (מבוסס על טבלת "עדיפות תיקון" בדוח הביקורת, חלק 4):**

1. 🔴 **ממצא 2.2 — פרמיה אורבנית ב-Zero Export** (מורכבות: **נמוכה**, שינוי שורה בודדת) — התיקון הכי מהיר ובעל הסיכון הכי נמוך. יש להוסיף `+ CALC_CONSTANTS.urban_premium` (רק אם `isUrban===true`) לביטוי `revSolar` בענף ה-`zeroExport` בתוך `runFinancialModel` (שורה ~442 ואילך). **הנחת יסוד שצריך לאמת לפני הקידוד**: האם הפרמיה חלה על 100% מהאנרגיה הנצרכת-עצמית, או רק על החלק שמזוכה בפועל — המקורות שנמצאו לא הבהירו זאת חד-משמעית.

2. 🔴 **ממצא 2.4 — שיעור צריכה עצמית תלוי-גודל-סוללה** (מורכבות: **גבוהה**) — דורש להחליף את `SELF_CONSUMPTION_RATE = 0.4` הקבוע בפונקציה שמקבלת את יחס (קיבולת סוללה / תפוקה יומית ממוצעת) ומחזירה שיעור עולה, עד תקרה ריאלית (הדוח מציע 85%-90% כתקרה, אך זה עוד לא סוכם/אומת — **החלטה פתוחה** שדורשת דיון עם המשתמש לפני מימוש, כי אין נוסחה "רשמית" מוסכמת לקשר הזה, רק היגיון פיזיקלי כללי).

3. 🔴 **ממצא 2.1 — מבנה מס פרטי דו-מסלולי** (מורכבות: **בינונית**) — דורש הרצת **שני** חישובי מס מקבילים (פטור מלא עד ~₪24,200 **לעומת** 10% שטוח מהשקל הראשון עד ₪120,000) ובחירת הטוב מביניהם, במקום הנוסחה הקיימת (25K exemption + 10% marginal). **⚠️ לפני מימוש: שני הסכומים (24,200 / 120,000) הגיעו ממקורות משניים (בלוגים/אתרי ייעוץ, לא טקסט חוק ראשוני) — יש לאמת מול פקיד שומה/רו"ח או פרסום רשמי של רשות המסים לפני שמקודדים אותם כברירת מחדל.**

4. 🟡 ממצאים 2.5–2.7 (בלאי קיבולת סוללה, אינפלציית OPEX, מודל ארביטראז' סטטיסטי-לא-שעתי) — עדיפות בינונית, מורכבות נמוכה-בינונית.

5. 🟢 ממצאים 3.1–3.9 (yield_base אזורי, שטח-פאנל מודרני, DC:AC ניתן-לעריכה, גגות מרובי-כיוונים, הצללה דינמית, **צריכת שבת אוטומטית מה-CSV — ערך גבוה למשתמש למרות עדיפות "קלה"**, שבירות פרסור CSV/DST, רשימת ערים לפרמיה אורבנית, שיעור היוון NPV ניתן-לעריכה) — לתעדף לפי מה שהמשתמש הבא מבקש.
