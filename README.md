# בראשית סולאר: אתר נפרד ב-GitHub + שרת נתונים ב-Apps Script

האתר (CRM, שלב 1 ניתוח צריכה, שלב 2 המלצת גודל, שלב 3 מודל פיננסי, הצעת מחיר) הוא קבצי HTML/JS סטטיים שמתארחים בנפרד, למשל ב-GitHub Pages.
Google Apps Script משמש **רק** כשרת נתונים: קריאה וכתיבה של קובץ ה-Google Sheets (ואופציונלית ייצוא Excel מעוצב). הכניסה למערכת נבדקת בשרת.

```
דפדפן ──► האתר הסטטי (GitHub Pages)  ──fetch POST {action,args,token}──►  Apps Script (Code.gs)  ──►  Google Sheets
              כניסה: שם משתמש+סיסמה או Google  ──►  אסימון זמני (נשמר בלשונית עד סגירתה)
```

בלי כתובת חיבור האתר רץ ב**מצב דמו**: הכל בדפדפן, בגיליון מדומה ב-`localStorage`, בלי Google ובלי כניסה.

## 1. פרסום האתר

1. מאגר חדש ב-GitHub. מעלים את **כל תוכן** התיקייה הזאת לשורש המאגר, **כולל התיקיות `apps-script`, `samples` ו-`tools`** (לא את התיקייה עצמה). הקובץ `server-local.js` בשורש נדרש למצב דמו ולייצוא "בדפדפן".
2. **Settings ← Pages**: Source = *Deploy from a branch*, הענף שלכם, תיקייה `/ (root)`.
3. הכתובת: `https://<משתמש>.github.io/<מאגר>/`. נדרש אינטרנט (SheetJS, PapaParse, Chart.js וגופנים נטענים מ-CDN).
4. הרצה מקומית: בתיקייה `python -m http.server 8000` ואז `http://localhost:8000` (פתיחה ישירה מ-`file://` לא תעבוד).

## 2. חיבור ל-Google Sheets

1. פותחים את קובץ ה-Sheets ← **Extensions ← Apps Script** (הפרויקט חייב להיות מקושר לקובץ).
2. מוחקים את קבצי ה-HTML הישנים ואת הקוד הישן, ומדביקים את `apps-script/Code.gs`.
3. **משתמשים** (רק מהעורך): בפונקציה `addUser_oneTime` ממלאים שם משתמש, סיסמה (10 תווים ומעלה), אימייל Google (לא חובה) ותפקיד (`editor` = מלא, `viewer` = צפייה בלבד), ומריצים. חוזרים על זה לכל משתמש. `removeUser_oneTime` מבטלת משתמש, `listUsers_oneTime` מציגה ביומן את הרשימה. הנתונים נשמרים בגיליון `משתמשים` (סיסמאות כ-hash בלבד).
4. **Deploy ← New deployment ← Web app**. *Execute as*: **Me**. *Who has access*: **Anyone**. מעתיקים את הכתובת שמסתיימת ב-`/exec`.
5. באתר: בסרגל התחתון **חיבור** ← כתובת ← **בדיקת חיבור** ← **שמירה והפעלה**. האתר יציג מסך כניסה. אפשר גם לקבוע את הכתובת לכולם ב-`config.js` (`API_URL`).
6. מומלץ: להיכנס ל-`selftest.html` ולהריץ את הבדיקה העצמית (סעיף 5).

אחרי שינוי קוד בשרת: **Deploy ← Manage deployments ← עריכה ← New version**.

### כניסה עם Google (אופציונלי)

1. ב-Google Cloud Console: **APIs & Services ← Credentials ← Create credentials ← OAuth client ID ← Web application**. ב-*Authorized JavaScript origins* מוסיפים את כתובת האתר (למשל `https://<משתמש>.github.io`). מעתיקים את ה-Client ID.
2. בשרת: מדביקים אותו ב-`setGoogleClientId_oneTime` ומריצים. באתר: מדביקים אותו ב-`GOOGLE_CLIENT_ID` ב-`config.js`.
3. לכל משתמש שייכנס עם Google מזינים ב-`addUser_oneTime` את **אימייל ה-Google שלו** (סיסמה אפשר להשאיר ריקה).

## 3. כניסה והרשאות

- **תפקידים:** `editor` רואה וכותב. `viewer` רואה בלבד: הכתיבה נחסמת באתר ובשרת (`forbidden`).
- **משך כניסה:** עד סגירת הלשונית. האסימון נשמר ב-`sessionStorage` ומשותף ללשוניות שנפתחות מהאתר. בשרת הוא תקף עד 6 שעות. ביטול משתמש נכנס לתוקף תוך דקה.
- **ניחוש סיסמאות:** אחרי 5 ניסיונות כושלים לאותו שם משתמש הכניסה ננעלת ל-15 דקות (הגנה חלקית: Apps Script לא רואה כתובות IP).
- **סיסמאות:** נשמרות כ-HMAC-SHA256 עם salt לכל משתמש ו"פלפל" סודי בשרת (Script Property). ל-Apps Script אין bcrypt, לכן השתמשו בסיסמאות ארוכות. אל תשתפו את גיליון `משתמשים`.
- **מפתח שירות ישן (`BS_API_KEY`):** עדיין נתמך כתפקיד `editor` (לאפליקציית המובייל ולכלים). למחיקה: מוחקים את ה-Script Property.

## 4. אבטחה: מה כן ומה לא

- רק הפעולות שב-`API_ACTIONS_` ניתנות לקריאה מרחוק, וכולן דורשות כניסה. אין הגשת HTML ואין `google.script.run`. ניהול משתמשים אינו חשוף ברשת.
- **קוד האתר ב-GitHub Pages גלוי** לכל מי שיש לו את הכתובת (כולל התעריפים והנוסחאות). הכניסה מגינה על **הנתונים** בגיליון, לא על הקוד. להסתרת הקוד יש לשים את האתר מאחורי שירות עם הרשאות.
- האסימון נשמר בדפדפן (`sessionStorage`): אל תפתחו את האתר במחשב לא מהימן.

## 5. בדיקה עצמית (`selftest.html`)

מריצה את כל הפונקציות מול השרת: טעינת כל הדפים, חיבור והרשאות, קריאה וכתיבה של כל עמודות הלקוח (רק ללקוח הבדיקה שבחרתם, למשל "דוגמא"), וייצוא Excel קטן ובגודל מלא (בדיקת מגבלות וזמן). בסוף "העתק דוח" מעתיק טבלת ✅🟡🔴 להדבקה.

## 6. ייצוא Excel

- **server** (ברירת מחדל כשמחוברים): נוצר ב-Apps Script, עם צבעים וגרדיאנט (קובץ זמני ב-Drive שנמחק מיד).
- **client**: נוצר בדפדפן (SheetJS): ערכים ומיזוגים, **בלי צבעים**. מוגדר בחלון "חיבור".

## 7. מה לא כלול

- טופס הלקוח `Form.html` (הצפנה עם המפתח הציבורי של הפריסה) ואפליקציית המובייל: דורשים התאמה לארכיטקטורה הזאת.
- נתוני הדוגמה ב-`samples/` סינתטיים. התוצאות במצב דמו אינן כדאיות אמיתית.

## 8. לוח הגדרות (⚙️) ומבנה הקבצים

הדפים נערכים ישירות (`crm.html`, `consumption.html`, `sizing.html`, `finance.html`, `print.html`) ואין עוד שלב בנייה. העותקים והכלים הישנים נמצאים ב-`archive/` (ר' `archive/README.md`).

בכל דף יש כפתור **⚙️ הגדרות** בפינה העליונה. הוא פותח לוח עם כל הערכים המשוערים/הממוצעים שהיו קבועים בקוד: תעריפים ומדרגות, תפוקה שנתית, יחסי שטח גג, פרמטרי אגירה וממיר, מס, פחת, חיתוך ממוצעים, היסטי יום עברי, קואורדינטות שקיעה, הערכה גסה בהצעה, פיזור צריכה לפי סוג נכס ורשימת חגים.

- ההגדרות מוגדרות ב-`settings.js` (ברירות המחדל זהות לערכים שהיו בקוד, ונבדקות ב-`tools/tests`). הדפים קוראים אותן דרך `BS_SETTINGS`.
- נשמרים רק ערכים ששונו מברירת המחדל. שורה צהובה בלוח = שונה. `↺` מחזיר ערך בודד, "אפס הכול" מחזיר את כולם. יש ייצוא וייבוא JSON.
- השמירה היא בדפדפן (`localStorage`) **ובשרת** (גיליון `הגדרות מערכת`, דרך `getAppSettings` / `saveAppSettings` ב-`Code.gs`), כך שכל המשתמשים רואים אותן. משתמש "צפייה בלבד" קורא ולא כותב.
- **נדרשת פריסה מחדש של `Code.gs`** כדי שהשמירה בשרת תפעל. עד אז הלוח עובד ושומר בדפדפן בלבד, ומציג הודעה מתאימה.
- הערכים נטענים בעת פתיחת הדף, לכן אחרי שמירה יש לרענן.
- הכרעות בסתירות: תפוקה שנתית 1600 לכל המערכת (בהערכה הגסה בהצעה הייתה 1650); שטח גג 5.5 מ"ר/קוו"ט לשלבים 2-3 ו-7.5 לשדה "מערכת קיימת" בשלב 1 (שני ערכים נפרדים מתוך כוונה).

בדיקות: `node tools/tests/settings_server_test.js` (שרת, מול `Code.gs` האמיתי) ו-`node tools/tests/settings_ui_test.js` (ממשק, דורש `npm i jsdom@22`). בדיקת משתנים לא מוגדרים: `python3 tools/lint_undefined.py . <eslint>`.

## 9. פתרון תקלות

| הודעה | סיבה | פתרון |
|---|---|---|
| "לא ניתן להגיע לשרת הנתונים" | כתובת שגויה, אין אינטרנט, או חסימת CORS | ודאו שהכתובת מסתיימת ב-`/exec` ושהפריסה *Anyone* |
| "תשובה שאינה JSON" | הפריסה דורשת התחברות גוגל או הכתובת שגויה | פריסה חדשה עם *Who has access: Anyone* |
| `bad_credentials` | שם משתמש או סיסמה שגויים | לבדוק ב-`listUsers_oneTime`; לאפס סיסמה ב-`addUser_oneTime` עם אותו שם |
| `locked` | 5 ניסיונות כושלים | להמתין 15 דקות |
| `not_authorized` (Google) | האימייל לא ברשימת המשתמשים | להוסיף את האימייל ב-`addUser_oneTime` |
| `forbidden` | משתמש צפייה בלבד ניסה לכתוב | להחליף תפקיד ל-`editor` |
| `not_configured` | אין משתמשים ואין מפתח שירות | להריץ `addUser_oneTime` |
| ייצוא Excel בשרת איטי או נקטע | מגבלת 6 דקות ב-Apps Script | להפעיל Services ← Google Sheets API, או לעבור לייצוא `client` |
