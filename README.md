# בראשית סולאר: דמו ל-GitHub Pages

מערכת הצעות המחיר והניתוח של בראשית סולאר, כשהיא רצה כולה בדפדפן, בלי Google Apps Script ובלי Google Sheets.
אפשר לנסות את כל הזרימה: CRM, שלב 1 (ניתוח צריכה), שלב 2 (המלצת גודל), שלב 3 (מודל פיננסי), הצעת מחיר מודפסת וייצוא Excel.

> **זה דמו.** הנתונים נשמרים ב-`localStorage` של הדפדפן שלך בלבד. אל תזינו נתוני לקוחות אמיתיים.
> התוצאות (גודל מערכת מומלץ, תשואה) מחושבות על **נתוני דוגמה סינתטיים** ואינן מייצגות כדאיות אמיתית.

## איך מפרסמים

1. ב-GitHub: **New repository** (אפשר ציבורי), למשל `bereshit-demo`.
2. מעלים את **כל תוכן** התיקייה הזאת לשורש המאגר (Upload files). לא את התיקייה עצמה, אלא את מה שבתוכה.
3. **Settings ← Pages ← Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, תיקייה = `/ (root)`. שמירה.
4. אחרי דקה-שתיים הכתובת היא `https://<שם-משתמש>.github.io/<שם-המאגר>/`.
5. הדמו טוען ספריות (SheetJS, PapaParse, Chart.js, גופנים) מ-CDN, ולכן נדרש חיבור אינטרנט.

הרצה מקומית (במקום GitHub): בתיקייה הזאת `python -m http.server 8000` ואז `http://localhost:8000`. פתיחה ישירה של הקובץ (`file://`) לא תעבוד: הדפדפן חוסם את טעינת `code.js`.

## מה לנסות (מסלול מלא, כ-5 דקות)

1. נכנסים לכתובת. נפתח ה-CRM עם שני לקוחות לדוגמה. בוחרים את **דמו: משפחת כהן**.
2. לוחצים **התחל ניתוח צריכה (שלב 1)**.
3. בשלב 1: מעלים `samples/sample_iec_15min_2y.csv` (קובץ מונה סינתטי, רבע-שעה, שנתיים), לוחצים לעבד, ואז **אחד את כל המקורות**.
   בתצוגה המקדימה תופיע השוואה בין שתי שנים מלאות. אפשר גם להעלות `samples/sample_form_billing.json` (קובץ בפורמט הטופס: סוג נכס, חיוב חודשי וסדרה שעתית) ולראות איחוד של כמה מקורות.
4. **שמור והמשך** עובר לשלב 2. מזינים שטח גג (למשל 120), לוחצים **מצא גודל מערכת מומלץ**, ואז **החל המלצה** ו**שמור והמשך**.
5. בשלב 3 החישוב רץ אוטומטית. **שמור לתיק הלקוח וחזור** חוזר ל-CRM, ושם כפתור הלקוח מציג שהשלבים הושלמו.
6. בשלב 1 (אותו לקוח) אפשר ללחוץ **הורד דוחות נתונים ל-Excel**, ובסרגל הדמו (פינה שמאלית תחתונה) אפשר לפתוח את **הצעת המחיר** המודפסת.

## מה שונה מהפריסה האמיתית

| נושא | דמו | פריסה אמיתית |
|---|---|---|
| אחסון | `localStorage` בדפדפן (מפתחות `bsdemo:*`) | Google Sheets |
| לוגיקת שרת | `code.js` האמיתי, מורץ בדפדפן מול גיליון מדומה | Apps Script |
| ייצוא Excel | נוצר בדפדפן (SheetJS): ערכים ומיזוגים, **בלי צבעים וגרדיאנט** | נוצר ב-Sheets עם עיצוב |
| טופס לקוח והצפנה | לא כלול | `Form.html` + כלי פענוח |
| הרשאות, מפתח API, מובייל | אין | יש |

## פרטיות

`localStorage` שייך לכתובת האתר כולה (`<שם-משתמש>.github.io`), ולכן דפים אחרים של אותו משתמש יכולים לראות אותו. מפתחות הדמו מתחילים ב-`bsdemo:`.
לאיפוס: בסרגל הדמו **איפוס נתוני דמו**, או מחיקת נתוני האתר בדפדפן.

## בנייה מחדש מקבצי הייצור

```
python tools/build_demo.py <תיקיית קבצי הייצור> .
```

התיקייה חייבת להכיל `code.js`, `Index.html`, `ConsumptionAnalysis.html`, `SystemSizing.html`, `FinancialModel.html`, `PrintQuote.html`. הסקריפט מזריק את `gas-shim.js` לכל דף ומייצר מחדש את קבצי הדוגמה.

## פתרון תקלות

- **דף ריק או "טוען...":** פתחו את קונסולת הדפדפן (F12). שגיאת `code.js` אומרת שהדף נפתח מ-`file://` ולא משרת.
- **ייצוא Excel נכשל:** ספריית SheetJS לא נטענה (אין אינטרנט, או חסימת CDN).
- **נתונים "נתקעו":** איפוס נתוני דמו בסרגל.
