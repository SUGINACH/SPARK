2. בתא הראשון של העמודה החדשה (נניח תא B2), כתוב את הנוסחה: `=INT(A2)` (הנוסחה הזו לוקחת רק את התאריך ומתעלמת מהשעה).
3. גרור את הנוסחה עד סוף העמודה.
4. *חשוב:* שנה את העיצוב של העמודה החדשה ל"תאריך קצר" (Short Date) כדי שתראה תאריכים ולא מספרים.

**שלב ב': סיכום הנתונים (2 אפשרויות)**

**דרך מומלצת - טבלת ציר (Pivot Table):**
1. סמן את כל הטבלה שלך (כולל הכותרות).
2. עבור ללשונית **הוספה (Insert)** ולחץ על **טבלת ציר (Pivot Table)**.
3. בחלון של טבלת הציר:
   * גרור את העמודה **"תאריך בלבד"** לאזור ה**שורות (Rows)**.
   * גרור את העמודה **"סוג תעריף"** לאזור ה**מסננים (Filters)** (או לעמודות).
   * גרור את העמודה **"קוט"ש"** לאזור ה**ערכים (Values)**. (וודא שזה מוגדר כ-Sum / סכום ולא Count / ספירה).
4. למעלה במסנן שנוצר, סנן כך שתראה רק **"פסגה"**.
*התוצאה:* רשימה של כל הימים, ובצד הסכום הכולל של קוט"ש שנצרך בשעות הפסגה בלבד באותו יום.

**דרך חלופית - שימוש בנוסחה (SUMIFS):**
אם יש לך רשימה של התאריכים בעמודה נפרדת (למשל עמודה E), תוכל לכתוב בעמודה F את הנוסחה הבאה:
`=SUMIFS(C:C, B:B, E2, D:D, "פסגה")`
*(בהנחה ש-C זו עמודת הקוט"ש, B זו עמודת 'תאריך בלבד', E2 זה התאריך הספציפי שאתה בודק, ו-D זו עמודת סוג התעריף).*

### אפשרות 2: קוד פייתון (Pandas)
אם אתה מעדיף לכתוב סקריפט קצר שייקח את קובץ ה-CSV ויוציא קובץ CSV חדש ומסוכם, הנה הקוד:

```python
import pandas as pd

# 1. טעינת קובץ ה-CSV
df = pd.read_csv('your_file.csv')

# הנחת שמות העמודות (יש לשנות בהתאם לשמות האמיתיים בקובץ שלך):
# 'datetime' = תאריך ושעה
# 'tariff_type' = סוג תעריף
# 'kwh' = סכום קוט"ש

# 2. המרת עמודת התאריך והשעה לפורמט תאריך של פנדס ויצירת עמודת 'תאריך בלבד'
df['datetime'] = pd.to_datetime(df['datetime'])
df['date'] = df['datetime'].dt.date

# 3. סינון רק של שעות ה"פסגה"
peak_df = df[df['tariff_type'] == 'פסגה']

# 4. קיבוץ לפי תאריך (יומי) וסיכום צריכת הקוט"ש
daily_peak_kwh = peak_df.groupby('date')['kwh'].sum().reset_index()

# 5. שמירה לקובץ חדש או הדפסה
print(daily_peak_kwh)
daily_peak_kwh.to_csv('daily_peak_summary.csv', index=False)
```

### מה יש בקובץ הזה?
1. **הסבר עסקי נקי:** ללא קוד או טכנולוגיה, רק תיאור מפורט של מה נכנס, מה יוצא, ולמה.

4. **כללי מקרי קצה:** סיכום של הבעיות שעלינו עליהן בדרך (כמו תאריכים ומספרים שנקראים כטקסט) ואיך התהליך צריך להתגבר עליהן.
