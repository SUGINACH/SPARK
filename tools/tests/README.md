# בדיקות דפדפן ושרת (לא חובה לפריסה)

מריצות את כל הזרימה בדפדפן (Playwright) מול **שרת בדיקה מקומי** (`fake_gas_server.js`) שמחקה את נקודת הקצה של Apps Script: POST ל-`/exec`, הפניה 302, בלי preflight, עם `CacheService`, `PropertiesService`, HMAC ו-tokeninfo של Google מדומים, ו-`Code.gs` האמיתי על גיליון מדומה.
הבדיקות לא מוכיחות התנהגות של Google עצמו (CORS, מכסות, זמני ריצה, Google Sign-In אמיתי): את זה בודקים בפריסה אמיתית, ובדף `selftest.html` שבאתר.

דרישות: `pip install playwright && playwright install chromium`, ו-Node. בתיקייה שמכילה את תיקיית האתר: `npm i papaparse@5.4.1 xlsx@0.18.5 chart.js@4.4.1 eslint@8` (תיקיית `node_deps`). הספריות מ-CDN מוחלפות בקבצים מקומיים בזמן הבדיקה.
משתני סביבה: `BS_WORK` (התיקייה שמכילה את האתר ואת `node_deps`, ברירת מחדל `/home/claude/work`), `BS_SITE` (שם תיקיית האתר, ברירת מחדל `site`).

| קובץ | מה בודק |
|---|---|
| `auth_server_test.js` | כניסה בשרת (41 בדיקות): סיסמה, תפקידים, נעילה, פקיעה, ביטול משתמש, Google, אחסון סיסמאות |
| `api_p1.py` ← `api_p2.py` ← `api_p3.py` | זרימה מלאה עם מפתח שירות: CRM, שלבים 1-3, שמירת עמודות, ייצוא, הצעה. `api_p1` מאפס מצב |
